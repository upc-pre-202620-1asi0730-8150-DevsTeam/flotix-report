# Capítulo III: Requirements Specification

## 3.1. User Stories

Las Epics se organizan según los bounded contexts implementados en la Web Application de Flotix: Vehicle & Fleet Management; Fuel Control; Maintenance Management; Incident Management; Real-Time Monitoring / Fleet Tracking; Alerts & Notifications; Digital Experience / IoT Commerce; y Reporting & Analytics. Adicionalmente, la Epic EP09 agrupa las historias del Landing Page, redactadas con el rol visitante. Cada User Story se redacta desde la perspectiva de los segmentos objetivo (Dueño, Conductor y Mecánica) y de los visitantes del Landing Page e incluye criterios de aceptación en estructura Gherkin. Adicionalmente, las historias técnicas (TS01 a TS31) se redactan con el rol Developer, respaldan la implementación de los servicios del Backend y cubren los bounded contexts de la Web Application. Sus criterios de aceptación describen escenarios de interacción request/response del RESTful API en estructura Gherkin.
