# Capítulo III: Requirements Specification

## 3.1. User Stories

| **US04** | Listar vehículos | Como Dueño, Quiero visualizar la lista completa de mis vehículos con su estado, Para tener una vista general de mi operación. | **Escenario 1: Lista con datos.** Given que accede al módulo de vehículos; When carga la página; Then visualiza una tabla con placa, tipo, estado y kilometraje.<br><br>**Escenario 2: Sin vehículos.** Given que no ha registrado vehículos; When ingresa al módulo; Then muestra "Aún no tienes vehículos registrados". | EP01 |

| **US06** | Asignar conductor a vehículo | Como Dueño, Quiero asignar un conductor a un vehículo disponible, Para habilitar la operación de esa unidad. | **Escenario 1: Asignación exitosa.** Given que selecciona un conductor y un vehículo disponible; When confirma; Then queda registrada la asignación.<br><br>**Escenario 2: Conductor ya asignado.** Given que el conductor ya tiene un vehículo activo; When intenta asignarlo a otro; Then el sistema advierte del conflicto. | EP01 |

| **US09** | Ver historial de consumo de combustible | Como Dueño, Quiero visualizar el historial de consumo de combustible por vehículo, Para identificar patrones de gasto. | **Escenario 1: Historial con registros.** Given que el vehículo tiene cargas registradas; When accede al historial; Then visualiza fecha, litros y rendimiento.<br><br>**Escenario 2: Sin registros.** Given que no existen cargas; When consulta; Then muestra "Sin registros de combustible". | EP02 |
| **US10** | Recibir alerta de consumo anómalo | Como Dueño, Quiero recibir una alerta cuando el rendimiento de un vehículo se desvíe del promedio esperado, Para investigar la causa a tiempo. | **Escenario 1: Alerta generada.** Given que el rendimiento cae por debajo del umbral configurado; When el sistema procesa el nuevo registro; Then genera una alerta visible en el dashboard.<br><br>**Escenario 2: Consumo dentro del rango.** Given que el rendimiento es normal; When se registra la carga; Then no se genera ninguna alerta. | EP02 |
| **US11** | Ver reporte de eficiencia de combustible | Como Dueño, Quiero generar un reporte comparativo de eficiencia entre vehículos, Para identificar cuáles requieren revisión. | **Escenario 1: Reporte generado.** Given un rango de fechas válido; When solicita el reporte; Then el sistema muestra el ranking de eficiencia por unidad.<br><br>**Escenario 2: Sin datos suficientes.** Given que hay vehículos con menos de 2 cargas registradas; When se genera el reporte; Then se excluyen del ranking con una nota aclaratoria. | EP02 |
